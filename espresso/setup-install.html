Instalação

Tradução do Quantum Espresso Tutorial de Pranab Das. As menções em primeira pessoa são do autor original.

Podemos instalar o Quantum ESPRESSO em notebooks ou desktops pessoais para rodar cálculos relativamente leves. Para tarefas computacionalmente pesadas, precisamos de recursos melhores, com muitos núcleos de CPU (ou GPU), memória, largura de banda e E/S de disco.

Ao longo deste tutorial, usarei um sistema Ubuntu para os cálculos menores, enquanto os cálculos mais pesados serão feitos em clusters de HPC.

Talvez a forma mais fácil de instalar o Quantum ESPRESSO seja pelo gerenciador de pacotes da sua distribuição Linux. Isso deve funcionar bem para nós e é a opção recomendada. Os comandos a seguir são para Ubuntu/Debian. Primeiro, garanta que o sistema está atualizado.

sudo apt update && sudo apt upgrade

Instale o Quantum ESPRESSO pelo repositório apt:

sudo apt install --no-install-recommends \
    libfftw3-dev \
    quantum-espresso
💡 Dica

Binários pré-compilados do Quantum ESPRESSO para Ubuntu estão nos releases do meu repositório no GitHub, para facilitar a instalação. Veja as notas de cada release para mais detalhes sobre como instalar.

Se quiser compilar a partir do código-fonte, estes são os passos de instalação do Quantum ESPRESSO 7.2 em um sistema Ubuntu (LTS 22.04). Vou compilar para um único processador. Primeiro instale as bibliotecas e dependências recomendadas:

sudo apt install --no-install-recommends \
    autoconf \
    build-essential \
    ca-certificates \
    gfortran \
    libblas3 \
    libc6 \
    libfftw3-dev \
    libgcc-s1 \
    liblapack-dev \
    wget

Se quiser compilar para processamento paralelo, instale também:

sudo apt install --no-install-recommends \
    libopenmpi-dev \
    libscalapack-openmpi-dev \
    libelpa17  #  use libelpa4 on Ubuntu 20.04

Baixe o Quantum ESPRESSO (a versão mais recente era a 7.2 quando este texto foi escrito):

wget https://gitlab.com/QEF/q-e/-/archive/qe-7.2/q-e-qe-7.2.tar.gz

Descompacte o código-fonte:

tar -zxvf q-e-qe-7.2.tar.gz

Entre no diretório do QE e rode o configure:

cd q-e-qe-7.2
./configure

Aqui podemos passar várias opções de configuração. Leia o manual para entendê-las bem. Na maioria dos casos, porém, os valores padrão funcionam: o configure deve detectar a configuração do sistema automaticamente. Se não obtiver o que deseja, experimente as diversas flags do configure.

⚠️ Cuidado

Note que alguns programas/utilitários que acompanham o Quantum ESPRESSO podem não funcionar corretamente com compilação paralela; para eles, pode ser preciso compilar em modo serial com a opção ./configure --disable-parallel, caso o modo paralelo seja detectado automaticamente.

Por fim, compile o código-fonte e gere os executáveis:

# compile individual packages
make pw
# or compile everything
make all
# we can parallelize e.g., below command uses 4 CPUs
make -j4 all

Os executáveis (ou links simbólicos para eles) ficarão no diretório bin. É uma boa ideia incluir esse caminho no seu arquivo .bashrc (ou .zshrc, ou o do shell que você usa):

# use the correct path if it differs from mine
echo 'export PATH="/root/q-e-qe-7.2/bin:$PATH"' >> ~/.bashrc

Por fim, talvez seja preciso reiniciar o terminal ou rodar source .bashrc.

source ~/.bashrc

Você pode compilar a documentação entrando em um diretório específico (por exemplo, PW ou PP) e executando (é preciso ter LaTeX instalado):

make doc

Se quiser a documentação em PDF, use também os comandos latex:

pdflatex filename.tex

Agora podemos rodar o pw.x (ou qualquer outro programa) do Quantum ESPRESSO com mpirun, usando o comando:

pw.x -inp inputfile > outputfile
# For parallel version
mpirun -np 12 pw.x -inp inputfile > outputfile

Onde -np 12 define o número de processadores e -inp indica o arquivo de entrada. Também é possível usar -i, -in, -input ou até o redirecionamento da entrada padrão <. Mas atenção: alguns sistemas podem não interpretar todas essas opções; acho que a opção mais segura é -i.

Terminada a instalação, opcionalmente podemos rodar os testes para ver se tudo deu certo. Entre no diretório test-suite e rode

make run-tests

Se estiver tudo bem, veremos mensagens Passed e podemos seguir em frente.

⚠️ Cuidado

Note que os passos acima podem não ser a forma mais otimizada de rodar o Quantum ESPRESSO no seu computador. Há várias implementações da mesma biblioteca; por exemplo, é possível trocar o OpenMPI pelas implementações Intel MKL ou MPICH. Pesquise por conta própria ou peça ajuda a alguém que entenda de computação de alto desempenho.

Instalando o PWTK

Vamos instalar um pacote de scripts muito prático, o PWscf Toolkit (PWTK). Primeiro instale as seguintes dependências:

sudo apt install tcl tcllib

Baixe o arquivo em http://pwtk.ijs.si/download/pwtk-2.0.tar.gz

wget "http://pwtk.ijs.si/download/pwtk-2.0.tar.gz"

O comando acima baixa e salva o arquivo no diretório atual. Em seguida, basta descompactá-lo (não é preciso compilar):

tar -zxvf pwtk-2.0.tar.gz

Adicione o caminho (ajuste conforme o seu caso) ao .bashrc:

echo 'export PATH="/root/pwtk-2.0:$PATH"' >> ~/.bashrc
source ~/.bashrc
