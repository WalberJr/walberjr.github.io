Jupyter notebooks

Há várias formas de rodar o JupyterLab no seu computador.

1. Instalar no seu computador

  • Instale o Python 3 no seu computador
    # on ubuntu / debian
apt install python3 python3-pip
  • Instale os pacotes Python necessários no seu computador
    pip3 install --upgrade -r requirements.txt
# or
pip3 install --upgrade numpy scipy matplotlib jupyterlab
  • Rode o JupyterLab
    jupyter-lab
# or the classic jupyter notebook
jupyter-notebook

2. Instalar os pacotes Python com virtualenv

  • Instale o Python 3 e o virtualenv no seu computador
    pip3 install --upgrade virtualenv
  • Crie o ambiente virtual no diretório do projeto
    cd qe-dft
virtualenv venv
  • Ative o ambiente virtual
    source venv/bin/activate
  • Instale os pacotes Python necessários dentro do virtualenv
  • Inicie o JupyterLab
  • Ao terminar, desative o virtualenv
    deactivate

3. Rodar em um contêiner

  • Instale o Docker
  • Crie uma imagem com o Python e os pacotes necessários instalados
    # build using the Dockerfile included in my github repo:
# https://github.com/pranabdas/espresso
# (adjust the Dockerfile according to your needs)
docker build -t espresso .
  • Rode um contêiner com redirecionamento de porta
    docker run -it --rm -p 8888:8888 -v ${PWD}:/home espresso bash
  • Inicie o JupyterLab
    jupyter-lab
