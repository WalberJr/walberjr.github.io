Otimização de estrutura

O pw.x pode otimizar só as posições atômicas (relax) ou as posições e a célula (vc-relax), usando o algoritmo BFGS.

relax — posições atômicas

Exige a namelist &IONS (pode ficar vazia):

&CONTROL
  calculation   = 'relax'
  prefix        = 'si'
  outdir        = './tmp'
  pseudo_dir    = './pseudo'
  etot_conv_thr = 1.0d-5
  forc_conv_thr = 1.0d-4
/
&SYSTEM
  ...
/
&ELECTRONS
  conv_thr = 1.0d-8
/
&IONS
  ion_dynamics = 'bfgs'
/

vc-relax — posições e célula

Adicione também &CELL:

&CONTROL
  calculation = 'vc-relax'
  ...
/
&SYSTEM
  ...
/
&ELECTRONS
  conv_thr = 1.0d-8
/
&IONS
  ion_dynamics = 'bfgs'
/
&CELL
  cell_dynamics = 'bfgs'
  press         = 0.0
  press_conv_thr = 0.5
/

Acompanhando a otimização

grep '^!' si.vcrelax.out                 # energia a cada passo
grep "Total force" si.vcrelax.out         # força total
grep -A3 "CELL_PARAMETERS" si.vcrelax.out  # célula a cada passo
grep "bfgs converged" si.vcrelax.out

A estrutura final fica entre Begin final coordinates e End final coordinates.

⚠️ Atenção No vc-relax a base de ondas planas é fixada na célula inicial. Depois de convergir, rode um novo SCF com a estrutura final (ou repita o vc-relax) para obter a energia correta. Use também um ecutwfc mais alto que o necessário para a energia.
