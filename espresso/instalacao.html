Instalação

Escolha a opção mais simples para você. Para aprender, as opções 1 ou 2 são suficientes.

1. Ubuntu / Debian (apt)

sudo apt update
sudo apt install quantum-espresso

2. Conda (Linux e macOS)

conda create -n qe -c conda-forge qe
conda activate qe

3. Compilando a partir do código-fonte

Recomendado em clusters, para obter o melhor desempenho com as bibliotecas da máquina.

sudo apt install build-essential gfortran libopenmpi-dev libblas-dev liblapack-dev libfftw3-dev libscalapack-openmpi-dev
git clone https://gitlab.com/QEF/q-e.git
cd q-e
./configure
make -j4 pw pp
# os executáveis ficam em q-e/bin
export PATH=$PWD/bin:$PATH

Windows

Use o WSL (Subsistema Windows para Linux) com Ubuntu e siga a opção 1.

wsl --install -d Ubuntu

Testando

which pw.x
mpirun -np 4 pw.x -in scf.in > scf.out

Pseudopotenciais

O QE precisa de um arquivo .UPF para cada elemento. Boas fontes:

  • SSSP (Materials Cloud) — conjunto testado, com cortes recomendados.
  • Biblioteca oficial do QE / PSLibrary
  • PseudoDojo — norma-conservante.

Para os exemplos deste tutorial:

mkdir -p pseudo
wget -P pseudo https://pseudopotentials.quantum-espresso.org/upf_files/Si.pbe-n-rrkjus_psl.1.0.0.UPF
