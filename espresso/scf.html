Primeiro cálculo SCF

Vamos calcular a energia total do silício cristalino. Crie a pasta de trabalho:

mkdir -p ~/qe/si && cd ~/qe/si
mkdir -p pseudo tmp
wget -P pseudo https://pseudopotentials.quantum-espresso.org/upf_files/Si.pbe-n-rrkjus_psl.1.0.0.UPF

Arquivo de entrada si.scf.in

&CONTROL
  calculation = 'scf'
  prefix      = 'si'
  outdir      = './tmp'
  pseudo_dir  = './pseudo'
/
&SYSTEM
  ibrav     = 2
  celldm(1) = 10.26
  nat       = 2
  ntyp      = 1
  ecutwfc   = 30.0
  ecutrho   = 240.0
/
&ELECTRONS
  conv_thr = 1.0d-8
/
ATOMIC_SPECIES
  Si  28.086  Si.pbe-n-rrkjus_psl.1.0.0.UPF
ATOMIC_POSITIONS crystal
  Si  0.00  0.00  0.00
  Si  0.25  0.25  0.25
K_POINTS automatic
  8 8 8 0 0 0

Executando

pw.x -in si.scf.in > si.scf.out
# ou em paralelo:
mpirun -np 4 pw.x -in si.scf.in > si.scf.out

Lendo a saída

A energia total final é marcada com !:

grep '^!' si.scf.out
!    total energy              =        -XX.XXXXXXXX Ry

Outras linhas úteis:

grep "convergence has been achieved" si.scf.out   # quantas iterações
grep "highest occupied" si.scf.out              # topo da banda de valência (isolantes)
grep "the Fermi energy" si.scf.out              # energia de Fermi (metais)
grep "total   stress" -A3 si.scf.out            # tensão (com tstress = .true.)
⚠️ Metais Para metais, adicione em &SYSTEM: occupations = 'smearing', smearing = 'mv' e degauss = 0.02.
