Boas-vindas

Este tutorial é resultado das minhas anotações pessoais enquanto tentava (e ainda tento) aprender cálculos de Teoria do Funcional da Densidade. Não sou especialista no assunto. Compartilho estas notas aqui caso ajudem você a começar. Vou citar vários outros materiais que estou seguindo. Espero que este tutorial seja útil.

Os arquivos de entrada do Quantum ESPRESSO, os Jupyter notebooks (com código Python para as visualizações) e outros arquivos relacionados a este tutorial estão no GitHub: pranabdas/espresso. Você pode clonar o repositório na sua máquina:

git clone https://github.com/pranabdas/espresso.git

Ou, se não tiver o git instalado, baixe uma cópia compactada do repositório aqui.

Convenção de nomes de arquivos

Recentemente decidi seguir um padrão específico para os nomes dos arquivos, mas você pode escolher o que funcionar melhor para você. Note que nem todos os arquivos de exemplo deste tutorial seguem essa convenção ainda.

{program}.{calculation}.{system}.{in, out}
{program}.{calculation}.{system_description}.{in, out}
{pw, pp, ...}.{scf, bands, ...}.{silicon, al_slab}.{in, out}

Exemplo: pw.bands.silicon.in → arquivo de entrada do cálculo de bandas com o programa PWscf para o silício.

Para scripts do PWTK, usaremos a extensão .pwtk (por exemplo, silicon_vc_relax.pwtk).

Conversão de unidades

  • 1 Bohr = 0,529177249 Å
  • 1 Rydberg (Ry) = 13,6056981 eV.

Conversor de Ångström para Bohr: constantes de rede costumam ser dadas em ångström; use a relação abaixo para converter para Bohr.

1 Å = 1,8897259886 Bohr.
