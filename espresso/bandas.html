Estrutura de bandas

O cálculo de bandas tem três passos: SCF → bands (pw.x) → bands.x.

1. SCF

Rode o SCF normalmente. Ele grava a densidade em ./tmp.

2. Cálculo não autoconsistente ao longo do caminho

Copie o input do SCF para si.bands.in e mude três coisas: calculation = 'bands', inclua nbnd (para ver bandas de condução) e troque o card K_POINTS pelo caminho de alta simetria da rede FCC (L–Γ–X–W–K–Γ):

&CONTROL
  calculation = 'bands'
  prefix      = 'si'
  outdir      = './tmp'
  pseudo_dir  = './pseudo'
/
&SYSTEM
  ibrav     = 2
  celldm(1) = 10.26
  nat       = 2
  ntyp      = 1
  ecutwfc   = 30.0
  ecutrho   = 240.0
  nbnd      = 8
/
&ELECTRONS
/
ATOMIC_SPECIES
  Si  28.086  Si.pbe-n-rrkjus_psl.1.0.0.UPF
ATOMIC_POSITIONS crystal
  Si  0.00  0.00  0.00
  Si  0.25  0.25  0.25
K_POINTS tpiba_b
6
  0.50 0.50 0.50  20  ! L
  0.00 0.00 0.00  20  ! G
  1.00 0.00 0.00  10  ! X
  1.00 0.50 0.00  10  ! W
  0.75 0.75 0.00  20  ! K
  0.00 0.00 0.00   1  ! G
pw.x -in si.bands.in > si.bands.out

3. bands.x

&BANDS
  prefix  = 'si'
  outdir  = './tmp'
  filband = 'si_bands.dat'
/
bands.x -in si.bandspp.in > si.bandspp.out

O arquivo si_bands.dat.gnu tem duas colunas (distância k, energia em eV), uma banda por bloco.

4. Gráfico (Python)

import numpy as np
import matplotlib.pyplot as plt

Ef = 6.2   # SUBSTITUA pelo "highest occupied level" do seu SCF (eV)
data = np.loadtxt("si_bands.dat.gnu")
k = np.unique(data[:, 0])
bands = data[:, 1].reshape(-1, len(k))

for b in bands:
    plt.plot(k, b - Ef, c="royalblue")

# posições dos pontos de alta simetria: veja "high-symmetry point" em si.bandspp.out
plt.axhline(0, ls="--", c="gray")
plt.ylabel("E - E$_F$ (eV)")
plt.xlim(k[0], k[-1])
plt.savefig("bandas.png", dpi=200)
💡 Dica Os valores de x de cada ponto de alta simetria aparecem em si.bandspp.out na linha high-symmetry point. Use-os em plt.xticks. Para gerar caminhos de outras redes, use o SeeK-path.
