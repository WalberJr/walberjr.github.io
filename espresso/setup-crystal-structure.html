Estrutura cristalina

Bancos de dados de estruturas

Cálculos de teoria do funcional da densidade (DFT) são ab initio, ou seja, feitos do zero a partir dos parâmetros de entrada. Para fazer um cálculo DFT precisamos fornecer a estrutura cristalina. Estruturas cristalinas estão amplamente disponíveis no formato Crystallographic Information File (.CIF). Há vários bancos de dados onde você pode procurar estruturas cristalinas.

  • http://crystallography.net/cod/
  • https://materialsproject.org
  • https://mpds.io/
  • https://icsd.fiz-karlsruhe.de/index.xhtml
  • http://aflowlib.org/CrystalDatabase/
  • http://crystdb.nims.go.jp/crystdb/search-materials

No Quantum ESPRESSO, a estrutura é informada pelo número ibrav e pelos valores de celldm correspondentes, ou pelas constantes de rede e os cossenos dos ângulos entre os eixos. Também é possível usar ibrav=0 e fornecer os vetores da rede em CELL_PARAMETERS.

⛔ Perigo

Com ibrav=0, os vetores da rede precisam ser informados com um número suficientemente grande de casas decimais; caso contrário, a detecção de simetria pode falhar e surgir problemas estranhos.

Ferramentas úteis:

Vesta - https://jp-minerals.org/vesta/en/. Ajuda a visualizar estruturas cristalinas, criar e modificar supercélulas e estruturas, entre muitas outras funções úteis.

Podemos preparar o arquivo de entrada do Quantum ESPRESSO com o utilitário cif2cell. Se não tiver o cif2cell instalado, use o pip para instalar:

sudo pip3 install cif2cell

Talvez seja preciso adicioná-lo manualmente ao caminho no seu .bashrc:

export PATH="/home/pranab/.local/lib/python3.8/site-packages/:$PATH"

Rodando o comando cif2cell:

cif2cell file.cif -p quantum-espresso -o inputfile.in

XCrySDen

Você pode explorar a estrutura cristalina, encontrar o caminho de pontos k e muito mais com o aplicativo XCrySDen - http://www.xcrysden.org

Para algumas funções, o XCrySDen precisa da calculadora bc. No Ubuntu/Debian:

sudo apt update
sudo apt install bc xcrysden

Instalação manual:

# instala as dependências
sudo apt install --no-install-recommends bc tk libglu1-mesa libtogl2 \
      libfftw3-3 libxmu6 imagemagick openbabel libgfortran5

# baixa e descompacta a versão mais recente do XCrySDen
wget http://www.xcrysden.org/download/xcrysden-1.6.2-linux_x86_64-shared.tar.gz
tar -zxvf xcrysden-1.6.2-linux_x86_64-shared.tar.gz

# inicia o programa (supondo que foi descompactado na sua pasta pessoal)
~/xcrysden-1.6.2-bin-shared/xcrysden

Se estiver no WSL, instale um servidor X (Xming, no Windows) no sistema hospedeiro e defina export DISPLAY=:0 na sua instância do WSL.
