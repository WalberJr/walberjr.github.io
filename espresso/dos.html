DOS e PDOS

A densidade de estados precisa de uma malha de pontos k mais densa que a do SCF. O fluxo é: SCF → NSCF → dos.x e/ou projwfc.x.

1. NSCF

A partir do input do SCF, altere:

&CONTROL
  calculation = 'nscf'
  ...
/
&SYSTEM
  ...
  nbnd        = 8
  occupations = 'tetrahedra'
/
...
K_POINTS automatic
  16 16 16 0 0 0
pw.x -in si.nscf.in > si.nscf.out

2. DOS total — dos.x

&DOS
  prefix = 'si'
  outdir = './tmp'
  fildos = 'si.dos'
  Emin   = -10.0
  Emax   =  20.0
  DeltaE =  0.01
/
dos.x -in si.dos.in > si.dos.out

O arquivo si.dos contém: energia (eV), DOS e DOS integrada. A energia de Fermi aparece no cabeçalho.

3. DOS projetada — projwfc.x

&PROJWFC
  prefix  = 'si'
  outdir  = './tmp'
  filpdos = 'si.pdos'
  Emin    = -10.0
  Emax    =  20.0
  DeltaE  =  0.01
/
projwfc.x -in si.projwfc.in > si.projwfc.out

São gerados vários arquivos, por exemplo:

  • si.pdos.pdos_tot — DOS total e PDOS total
  • si.pdos.pdos_atm#1(Si)_wfc#1(s) — orbital s do átomo 1
  • si.pdos.pdos_atm#1(Si)_wfc#2(p) — orbitais p do átomo 1

Para somar as contribuições de todos os átomos de um elemento, use o sumpdos.x:

sumpdos.x 'si.pdos.pdos_atm#*(Si)_wfc#2(p)' > Si_p.dat

4. Gráfico (Python)

import numpy as np
import matplotlib.pyplot as plt

Ef = 6.2  # SUBSTITUA pelo valor do seu cálculo (eV)
E, dos, _ = np.loadtxt("si.dos", unpack=True)
s = np.loadtxt("si.pdos.pdos_atm#1(Si)_wfc#1(s)")
p = np.loadtxt("si.pdos.pdos_atm#1(Si)_wfc#2(p)")

plt.fill_between(E - Ef, dos, color="lightgray", label="Total")
plt.plot(s[:, 0] - Ef, 2 * s[:, 1], label="Si s")   # x2: dois átomos equivalentes
plt.plot(p[:, 0] - Ef, 2 * p[:, 1], label="Si p")
plt.axvline(0, ls="--", c="gray")
plt.xlabel("E - E$_F$ (eV)"); plt.ylabel("DOS (estados/eV)")
plt.legend(); plt.savefig("dos.png", dpi=200)
